# Site images

All pictures here are animated placeholder illustrations. Replace any of them with your own photos.

**Easiest way:** put your photo in this folder (e.g. `my-solar-job.jpg`) and change the matching
`image:` path in `lib/content.js`. Photos are cropped to fill their frame, so landscape shots (4:3 or 16:9) work best.

| File | Where it shows |
| --- | --- |
| `embedded.svg` | Home "Our core" section, Services → Embedded |
| `software.svg` | Home + Services → Web & Mobile |
| `engineering.svg` | Home + Services → Electrical Engineering |
| `training.svg` | Home + Services → Training, Training page banner |
| `workshop.svg` | About page "Our story" (set in `pages/about.js`) |
| `projects/*.svg` | Projects page and Home "Featured work" |

Tip: keep each photo under ~400 KB (export at ~1600px wide, JPG/WebP quality 75–80).
